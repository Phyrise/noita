# Noita · Spells & perks

[Open the app](https://phyrise.github.io/noita/)

Instant English search for 414 spells and 117 perks. Three views: images grouped by tier, cards, and names. Adjustable columns and local favorites. Unknown tiers are marked with `?` / “Non vérifié”.

The published app is self-contained in `index.html` (HTML, CSS, JavaScript, data and pixel sprites), with no backend or dependencies. Download the file to use it locally.

Tier sources: [spells](https://www.reddit.com/r/noita/comments/17o5pbj/a_public_branch_noita_spell_tier_list_since_i/) · [perks](https://www.reddit.com/r/noita/comments/l4zrag/2500_hours_of_noita_my_general_perk_tier_list_for/).
